# Checklist para cuando tengas la laptop

- [ ] Descomprimir el ZIP.
- [ ] Crear proyecto Supabase.
- [ ] Ejecutar 01_SCHEMA_COMPLETO.sql.
- [ ] Crear tu usuario en Authentication.
- [ ] Editar y ejecutar 02_CREAR_SUPER_ADMIN_Y_XOLITAS.sql.
- [ ] Opcional: ejecutar 03_DATOS_INICIALES_XOLITAS.sql.
- [ ] Pegar URL y publishable key en assets/js/config.js.
- [ ] Cambiar DEMO_MODE a false.
- [ ] Subir todos los archivos al repositorio Organizacion.
- [ ] Activar GitHub Pages.
- [ ] Abrir /Organizacion/admin/login.html.
- [ ] Crear un equipo de prueba.
- [ ] Verificar /Organizacion/{slug}/.
- [ ] Crear jugadora, liga y partido.
- [ ] Registrar gol en Modo partido y confirmar que el sitio público se actualiza.
- [ ] Cambiar branding y confirmar que solo afecta ese equipo.
