# Contrato visual del producto

La página pública de cada equipo parte directamente del diseño actual de Xolitas F.C. incluido en este repositorio.

## No cambia por equipo
- layout y orden de secciones
- tamaños, cards, modales y animaciones
- comportamiento responsive
- tipografías
- estructura del hero, jornadas, clasificación, plantilla, goleadoras, patrocinadores, próximo partido y footer
- estructura visual del dashboard y modo partido

## Sí cambia por equipo
- nombre y nombre corto
- escudo/logo/favicon
- colores de marca mediante variables CSS
- textos configurables de hero y secciones
- fotografías y datos de jugadoras
- partidos, ligas, estadísticas y clasificación
- patrocinadores
- contenido social y demás datos del tenant

Xolitas es la plantilla maestra y el tenant inicial. No debe rediseñarse al convertir la aplicación a multi-equipo.
